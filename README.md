# The Robot Vacuum's Best Excuse — entry

A program/v1 entry for the make.fun "The Robot Vacuum's Best
Excuse" bounty. `main.py` writes one excuse to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The excuse:

> That spot is under the couch, and so is my courage. I cleaned around the fear, thoroughly.

An honest machine: the corner was skipped, the fear was not,
and everything reachable was done thoroughly. See
`CANDIDATES.md` for the full draft list this winner was
picked from.
